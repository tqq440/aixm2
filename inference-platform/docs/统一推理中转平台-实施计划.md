## v2.17 当前增量：保留统一中转，新增独立主机 Node

2026-10-21 用户明确：只将 CPU/GPU 内存、显存管理交给业务侧；原统一受理、Redis 队列、调度、并发额度、结果保存、日志监控、鉴权、管理页面和 Linux 验收继续实施。此前讨论中“暂停中心队列、取消统一调度、结果全部由业务保存”的方案撤回，没有应用到日常执行。

确定调用链：**外部应用 → 入口 Node → 中心平台受理/排队/分配 → 目标 Node → ASR/YOLO/LLM**。外部只访问 Node；入口和目标 Node 可以相同。中心负责统一应用身份和 API Key，Node 不建立独立应用归属。

| 层级 | 职责 |
|---|---|
| 中心平台 | 服务目录、统一受理与鉴权、Redis 通知、SQLite 权威任务与结果、目标选择、应用/目标/共享组额度、事件与监控汇总、管理页面 |
| 主机 Node | 独立配置/SQLite/日志、已登记业务服务控制、接收本机业务上报、转发内部授权调用、主机资源采集、Docker 启停升级 |
| 业务服务 | 模型加载、实际推理、内部执行队列、进度和结果、生命周期上报及排空 |
| 师兄负责的业务侧 | CPU/GPU 内存与显存管理，以及真实 ASR 内部队列、上报和排空接入 |

### 原计划保留与 Node 接入规则

- 中心 Redis Streams、SQLite outbox、按服务/模型轮询、GPU 优先、合条件 ASR CPU 承接、LLM 两秒短等待及共享并发额度全部保留。额度是派发预算，不是显存分配或模型缓存管理。
- 中心队列管理尚未派出的任务；ASR 内部队列管理已交给服务的任务，后者继续占用中心预约额度直到可信终态。同一任务不重复建档或计额，Node 本身没有推理队列。
- 提交和上传文件在中心持久化后才返回受理；中心不可用时新提交返回暂不可用。中心保存结果后才确认平台成功及队列消息；结果未明不自动重发或释放占位。
- Node 使用中心签发的内部执行身份，关联调用编号、执行次数、目标和修订；外部 API Key 不能绕过中心预约直接执行。重复派发返回已有记录，不重做推理。
- 在途结果需要 Node 恢复记录和向中心重传，中心失联后不通过重做推理恢复结果。LLM 保留原流式结束验证，普通断线不算成功。
- 业务向本机 Node 上报，Node 向中心提供快照。平台排队、ASR 内部排队、已分配设备、服务实际设备分别表达，缺接口记录缺口。
- Node 独立 Linux 系统服务开机自启，首版生产目标 Docker。只控制登记的服务/版本/脚本；停止升级先关闭新提交并排空，未确认不强停。Node 重启核对已有容器，Node 单独退出不停止业务容器。

## 统一执行规则

离线按逻辑服务和模型分队列，轮询当前可领取任务；LLM 默认短等待 2 秒。所有调用在同一 SQLite 事务检查应用、目标与全部共享资源组，held/uncertain 均占额。新请求固定目录修订，选择目标后不因编辑配置改投。

GPU 优先只使用可信设备、模型兼容、健康和容量资料；CPU 自动承接限尚未执行且具备同模型和性能证据的请求。ASR 首批复用既有评估；YOLO/LLM 首批使用固定 CPU/GPU 目标，后续按实测补充。未知设备不推为空闲，当前真实 ASR unknown/1 不扩大。

任务、幂等与待投递事件同事务落库，事务外投 Redis；收到通知后仍检查数据库执行资格。结果落库后确认消息，重复通知不重推理；Redis 故障可以有界受理离线任务，暂停新上游调用。在途结果仍落库，LLM 新请求返回暂不可用。结果未知不自动重发、换目标或释放许可。

## 日志与监控规则

模块 2 将受理、入队、等待原因、分配、调用、结果和容量事件与业务状态同事务保存；模块 4 增加最新上游监控快照，模块 5 开放时间线与查询。模块 1 先保存目录配置和连接检查事件，不伪造旧任务日志。

平台记录排队和已分配设备；进度、远端完成状态及实际执行设备按服务协议获取。设备声明与实际报告分字段，未知进度为空。同步有效最终响应、完整流式结束信号均可作为完成依据；health、普通 EOF、进度 100%、查询 404 不能单独证明完成。

后台采集默认每 5 秒、每服务并发 1、全局 4，失败退避至 60 秒；查询 HTTP 在事务外，身份、执行次数、修订和采集代次必须匹配。GET 仅读本地快照，多个页面不重复采集。查询失败保留最后可信状态和时间，不改推理终态、不重发、不释放未知容量。迟到完成追加记录，不改写原超时历史。

无查询接口或部署问题记录在接入问题清单，不阻塞公共开发。只有 job id 却无法查询完成/取得结果的异步服务不能冒充接入闭环。日志只存白名单信息，不保存密钥、音频、图片、聊天正文及原始上游响应。
