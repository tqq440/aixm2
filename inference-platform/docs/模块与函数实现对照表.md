## 演示时应说明的事实

当前真实链路是：**ASR/图片页面或HTTP上传 → M01校验 → M02保存输入并创建任务 → M05原子保存任务、幂等和待投递事件 → M08投递 → M07按能力通知 → M12/M14获取M05租约、读取M06输入并执行 → M05保存JSON结果 → M03查询交付**。失败时M08决定有限重试；取消先由M05裁决，M12/M14确认受管child停止。第十一部分页面只提交和查询，不绕过后台规则。

这是完整设计中的本机ASR/YOLO可运行子集，另保留第九部分独立本地链路：**本地图片 → 有界解码与尺寸归正 → 固定 CPU YOLOv5n → 一次 NMS 与原图坐标 → 新目录 JSON/PNG**。本地命令不会创建平台任务；异步图片任务走单独HTTP入口。第十二部分另有在线页面→M02准入→M13静态HTTP生成→M03事件→M13收尾链路，当前只由协议替身验证；真实LLM服务仍待提供。本机Node Agent已按ASR-2B实现；多节点资源调度、GPU、完整访问保护、外部对象／消息服务、指标告警和规模容量仍是后续工作。基础测试中明确使用的模型替身只验证流程；真实模型结果以阶段实测记录为证，不能由测试通过推导准确率或吞吐。
