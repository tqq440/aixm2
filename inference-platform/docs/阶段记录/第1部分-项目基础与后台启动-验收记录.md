## 发现的问题与处理

1. 工具终端加载 PowerShell profile 时 Conda 自动激活失败。直接使用 project311 Python 可正常运行；未修改用户 profile，README 提供不依赖自动激活的命令。
2. 受限执行沙箱不能安装到环境或访问本机网络。通过已授权范围的升级执行完成依赖安装、真实网络及停止测试；没有用 Flask 测试客户端代替真实 HTTP 验收。
3. Alembic 在此 Windows 环境按本地编码读取 INI，UTF-8 中文注释会解码失败。INI 已保持 ASCII，迁移实测通过。
4. 默认 pytest 临时目录在工具沙箱权限受限，改用项目内 `runtime/tmp` 下的专用测试目录；这些是测试数据，不是业务数据库。
5. `.env` 语法错误原会被 dotenv 忽略。已改为严格检查，损坏行明确报行号并阻止启动，新增回归测试。
6. 工具 PTY 注入 Ctrl+C 时会直接中断整个控制台会话，不能以此证明清理路径。最终验收使用 Windows CTRL_BREAK_EVENT：实际退出码 0、资源释放日志和端口关闭都已验证。用户手动 Ctrl+C 走 Python 的常规中断机制，操作方法已写入 README；未声称本次工具模拟完整复现了用户手动按键。
