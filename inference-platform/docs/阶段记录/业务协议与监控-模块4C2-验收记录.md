## 实现范围

- ASR Remote-V2/OpenAI Audio 实际 multipart HTTP；中心原上传读取、SHA/大小/时长核验、Node 解码并转换 WAV。
- YOLO `vision-json-v1`，逻辑模型、自定义类别、EXIF 归一尺寸与边界；与旧本地模型结果 schema 分离。
- LLM 文本 SSE 贯穿中心与 Node，结束原因加 `[DONE]` 才确认；普通 EOF、消费者关闭和异常不成功、不重放正文。
- 可选 `job-json-v1` 状态/结果/取消，严格关联调用编号、执行次数及两端修订；结果内联或独立获取。
- 后台进度、业务排队、可信远端状态和实际设备快照；设备默认 service 命名空间，不推定宿主 GPU 编号。
- 同服务不重叠/每 Node 采集进程最多 4、默认 5 秒、超时和退避/Retry-After；只读 GET 不查询业务。
- 显式中心 Node 执行器、进程锁、就绪探测、租约续期和结果采集；保留 Redis 故障门控与未知占位。
- 中心结果保存事件早于完成与容量释放；明确未发送的输入/门禁拒绝留持久证据；过期和迟到结果保留历史。
- 中心 0019、Node 独立 0004；旧配置不因可选字段改指纹，旧档案与结果跨监控迁移保持。

Node 没有新增推理队列。中心任务、额度及权威结果保留；业务内存/显存、模型加载/缓存和真实内部队列仍由业务侧负责。
