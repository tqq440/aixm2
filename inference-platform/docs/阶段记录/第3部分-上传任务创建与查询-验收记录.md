## 本部分实现

请求链路为 `controller/tasks → service/tasks → data/tasks + data/files`。控制器接收 HTTP，Schema 校验输入；Service 检查模型、语言和音频，裁决幂等；Data 负责文件和数据库持久化。Modules 只装配应用和提供一次性维护入口。

|---|---|
| `backend/config/asr/model_catalog.py`、`service/tasks/model_service.py` | M04 首批能力：固定 whisper-small、版本、99 个语言码和输入/输出能力；不表示实例已加载 |
| `backend/schema/tasks/task_schema.py` | 模型列表、上传表单、幂等头、分页、路径和返回格式；JSON camelCase |

## 当前接口契约

所有成功响应为 `{data, requestId}`；所有错误沿用 `{error, requestId}`。调用者固定为 `local-user`，这是本机简化标识，不是登录认证或多用户权限方案。

| 接口 | 输入与结果 |
|---|---|
| `GET /api/models` | 无查询参数；`data.items` 返回唯一固定模型的能力说明 |
| `POST /api/tasks/asr` | multipart，一个 `file`；可选 `modelId=whisper-small`、`language=zh/auto/支持的语言码`；必需 `Idempotency-Key` |
| `GET /api/tasks?page=1&pageSize=20` | page 为 1—1000000，pageSize 为 1—100；返回 items、total、page、pageSize，按创建时间和任务编号倒序 |
| `GET /api/tasks/{task_id}` | 32 位小写十六进制编号；返回任务详情，不存在为 404 |

幂等键长 1—128，首字符为字母/数字，其余允许字母、数字、点、下划线、冒号和短横线。首次保存返回 201；同键同内容返回 200，`data.replayed=true`；改变请求内容返回 409。相同音频配不同键可以创建不同任务，文件哈希不替代业务幂等键。

指纹包含契约版本、任务类型、固定模型 ID/版本、规范化参数、音频 SHA256 和字节数；文件显示名、请求编号不参与指纹。`auto` 规范化为语言 null。表单不接收 `audioPath`、`callerId`、执行计划版本等越权字段，拒绝重复参数和多个文件。上传文件名仅取最终显示名称，磁盘名称由服务器生成，不接受客户端服务器路径。

任务返回状态、编号、调用者、模型版本、语言、`executionPlanVersion`、文件显示名/大小/哈希/时长、UTC 创建/更新时间，以及“任务已保存，尚未接入自动执行流程。”。内部路径、对象引用和事件字段不对外输出。

模型目录描述能力，不检查或下载权重。提交时解码验证最多 20 MiB / 300 秒的音频；上限可按既有配置调低。总请求上限为音频大小上限加 64 KiB multipart 开销，表单解析内存上限 128 KiB，最多 8 个表单部分。最终只允许一份音频和规定的参数。独立审查发现并修复了 64 KiB 表单解析上限可能误拒绝跨块合法音频的问题，已有回归用例。

## 文件、事务与清理

1. 保存到 `runtime/uploads/staging/<uuid>.part`，分块计数和哈希，完整写入并同步后移至 `objects/<uuid>.audio`。
2. 解码和准入通过后，在一个 SQLite 事务内写入 `tasks`、`idempotency_records` 和 `dispatch_events`。唯一约束裁决同调用者同幂等键，外键关联档案与事件。
3. 初始 `attempt=0`、`execution_plan_version=1`、`dispatch_version=1`，通道为 `asr.whisper-small`。没有发布、消费、租约或重试循环。
4. 常规失败和重放立即删除本次多余文件。数据库提交异常后重新查询权威记录；确认已提交则返回原任务，确认未提交则补偿删除，无法确认则保留文件并返回 503，不虚报成功或盲删。
5. 维护仅处理超过 24 小时且无任何任务引用的 UUID 普通文件和临时残片；引用检查失败则停止。被引用文件不按年龄删除。未知名称、非普通文件、链接和目录联接点不作为普通音频删除。
6. 上传从保存到提交/复查/补偿与维护全过程共用跨进程锁，维护不会删正在受理的对象。5 秒未取得锁返回可重试的忙错误。一个上传根目录只能与一个数据库配套使用；没有验证分布式文件系统、多实例容量或断电恢复保证。

默认配置的维护预览已实际运行：退出 0，`applied=false`、`candidates=[]`、`deleted=0`，保留已有任务的音频。实际删除行为只在隔离测试目录验证，未删除默认运行目录中的文件。
