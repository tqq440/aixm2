## 实现

中心增加独立应用Key（只存摘要、一次显示）、原子轮换撤销、应用服务权限和并发额度。外部只访问入口Node，Node按公共路径白名单转发，中心同时验证入口凭据与应用Key；不转发Cookie、管理/执行凭据或任意URL。中心失联不本地接单，不重试推理，不形成Node任务队列。

公共ASR/YOLO提交复用原TaskRecord、幂等档案和InvocationService；文件核验后，任务、幂等、调用和outbox同事务提交。应用归属与Key分离；列表/详情/结果/下载/取消/事件/监控统一校验，跨应用返回404。公共开关启用后，远程旧业务/下载/管理接口被本机管理边界阻止，不能绕过公共鉴权。原本机兼容入口保留。

LLM保持默认两秒容量等待与Node桥接，自定义SSE转发；普通EOF/消费者提前关闭保持未知，不重放token。重复POST返回原元数据而不重新生成；聊天正文不持久化。平台分配设备与服务实际设备分开，服务缺进度接口如实显示。取消ACK不释放未知容量；迟到结果有lateResult标记，保留原历史。

前端新增应用/Key管理、状态筛选、任务时间线、进度/设备/错误与结果状态、节点缓存/显式就绪核查和额度账本；服务目录增加Node关联和状态内联结果声明。GET只读，页面不会额外触发业务查询。Key不写浏览器存储，完整值隐藏后清除。
