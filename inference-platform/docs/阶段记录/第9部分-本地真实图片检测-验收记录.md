## 3. 实现与命令

入口用法、图片限制、坐标说明和固定模型来源已写入[本地图片检测说明](../本地图片检测说明.md)。已实现以下分层：

- `config/vision` 固定模型标识、来源、权重哈希和 80 类标签，AppSettings 统一读取图片目录、线程数、字节和像素限额。
- `schema/vision` 校验本地请求和输出；Pydantic 统一使用 camelCase JSON，禁止非有限数值和越界框。
- `utils/image` 完成有界 JPEG/PNG 解码、EXIF 归正、透明白底、等比缩放填充、原始候选解析、按类别 NMS、原图坐标还原与 PNG 标注。
- `service/vision` 编排显式模型准备、CPU 加载、推理和输出校验；`data/vision` 保存模型清单/权重及 JSON/PNG。两份结果先写入临时目录，再发布完整的新结果目录，不覆盖旧结果。
- `modules/vision` 只提供 `prepare_model [--check]` 和 `detect_image` 命令；复用公共 CLI 的配置、日志、错误 JSON 与退出码，没有数据库写入或后台循环。

真实输出位于新目录中的 `result.json` 和 `annotated.png`；日志为 `runtime/logs/vision.log`。命令正常完成后退出，无需启动 API 或操作页面。数据库结构仍为 `20261013_0005`，本部分没有迁移。

实现对照仅将 M14-F03/F04/F05 对应到本机图片准备、检测和归一化子集；M14-F01/F02/F06/F07 的 Worker 初始化、投递执行、容量准入和 Agent 心跳仍未实现。
